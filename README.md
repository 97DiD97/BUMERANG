# Boomerang — плагин бумерангов для Paper 26.1.2

Медный, железный и алмазный бумеранг (кольца). Бросок на ПКМ, 3 отскока от стен и возврат к игроку.
Текстуры встроены в сам плагин — один файл `Boomerang.jar`.

## Как получить jar через GitHub

1. Создай новый репозиторий на github.com (кнопка **New**), например `boomerang`.
2. Загрузи в него **содержимое** этой папки (не саму папку, а то, что внутри):
   `.github`, `src`, `resourcepack`, `build.gradle.kts`, `settings.gradle.kts`, `.gitignore`.
   Проще всего: **Add file → Upload files** и перетащить всё. Папка `.github` скрытая —
   проверь, что в репозитории есть `.github/workflows/build.yml`.
3. Нажми **Commit changes**.
4. Вкладка **Actions**: идёт сборка (1–3 минуты). Зелёная галочка — готово.
5. На главной странице репозитория справа, в **Releases**, появится «Сборка 1» с файлом `Boomerang.jar`.
   Скачай его.

## Установка на сервер

1. Нужен сервер **Paper 26.1.2** (или форк) и Java 25.
2. Положи `Boomerang.jar` в папку `plugins`, перезапусти сервер.
3. Текстуры плагин сам отправляет игрокам при входе. Для этого он открывает TCP-порт **8165**
   (меняется в `plugins/Boomerang/config.yml`, `pack-port`) — его нужно открыть на хостинге/роутере.
   Если порт открыть нельзя, смотри комментарии про `pack-url` в `config.yml`
   или поставь `resource-pack: false` — тогда предметы будут выглядеть как слитки и алмаз.

## Команды

- `/boomerang give copper|iron|diamond [игрок]` — выдать бумеранг (для операторов)
- `/boomerang reload` — перезагрузить настройки
